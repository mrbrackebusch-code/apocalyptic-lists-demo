# Apocalyptic Lists — playable reference demo

Expand the simulator with **Fullscreen**; its portrait room is very small in the compact editor view. Move with arrows; **A** uses a nearby altar or gate; **B** beside an altar explains its list operation; **B** beside a moment watches it; **B** elsewhere opens the menu. Walk to the glowing top crystal and press **A** to **Release time** and run the current plan. Use the **Animation** hourglass or **Animation speed** menu item to cycle **0.5x / 1x / 2x / 4x**; walking stays the same.

On first launch with no saved progress record, this demo starts in Room 14 and unlocks all 27 rooms through **B → Revisit an unlocked room**. Later launches and code restarts resume the saved room and preserve progress. Explicitly resetting saved progress starts Room 01 and remains reset on restart. All 29 reference station programs are present; the learner starter remains blank.

Learner entry: [Build your first move list](https://arcade.makecode.com/#tutorial:https://github.com/mrbrackebusch-code/apocalyptic-lists/FIRST). This is an experimental owner-directed visual preview, with no new learner or classroom readiness claim.

Conserve usage indefinitely. Native source identity and existing compile provenance are in PREVIEW_RELEASE.json.
