# Apocalyptic Lists — playable reference demo

Expand the simulator with **Fullscreen**; its portrait room is very small in the compact editor view. Move with arrows; **A** uses a nearby altar or gate; **B** opens the menu. Choose **Release time** to run the current plan.

Starts in Room 14. All 27 rooms are unlocked through **B → Revisit an unlocked room**. All 29 reference station programs are present, so this is a ready-to-play demonstration rather than the blank learner starter. Code edits/restarts restore the review seed.

Learner entry: [Build your first move list](https://arcade.makecode.com/#tutorial:https://github.com/mrbrackebusch-code/apocalyptic-lists/FIRST). This is an experimental owner-directed visual preview, with no new learner or classroom readiness claim.

Conserve usage indefinitely. Native source identity and existing compile provenance are in PREVIEW_RELEASE.json.
