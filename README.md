# Apocalyptic Lists — ready-to-play demo

Use **Fullscreen** for the portrait room. Move with arrows; **A** uses nearby objects. **B** beside an altar explains its list operation; **B** beside a moment watches it; **B** elsewhere opens the menu. The glowing top crystal releases time; the hourglass cycles 0.5x / 1x / 2x / 4x animation without changing walking.

First launch starts in Room 14 with all 27 rooms available under **Revisit an unlocked room**. Later launches resume the saved room and speed. Erasing saved progress starts Room 01 and stays reset after restart. All 29 reference station programs are deliberately included here. [The learner tutorial](https://arcade.makecode.com/#tutorial:https://github.com/mrbrackebusch-code/apocalyptic-lists/FIRST) starts with blank editable Blocks and earns its own progress.

Conserve usage indefinitely. Exact source and native compile provenance are in PREVIEW_RELEASE.json.
